# 图片水印打码工具

纯浏览器本地处理的图片水印工具，适合身份证、驾照、护照等敏感证件图片的脱敏分享。

## 特点

- **纯本地处理** — 所有图片处理在浏览器中完成，不上传、不留存，绝不保留用户信息
- **实时预览** — 调整水印参数时即时刷新预览，所见即所得
- **多行水印** — 支持换行输入多行文字，每行独立平铺渲染
- **灵活样式** — 可调节文字颜色、透明度、角度、间距、字号
- **颜色预设** — 内置印章红、深灰、纯黑、白色快捷色块，点击即用
- **文字预设** — 常用水印短语一键填入，自动记住上次使用的文字
- **智能导出** — 自动匹配原图格式（JPEG/PNG/WebP），输出文件大小预估
- **大图适配** — 超大图片自动等比缩放，避免移动端卡顿
- **拍照上传** — 移动端支持直接调起相机拍摄证件照
- **剪贴板粘贴** — 桌面端支持 Ctrl+V 粘贴截图
- **空水印保护** — 水印文字为空时禁用下载，防止误导出未保护图片
- **一键分享** — 支持 Web Share API 直接调起系统分享面板（含微信），无需先下载再发送
- **响应式设计** — 适配桌面和移动端，手机端预览吸顶、参数调节不遮挡
